# Module API reference

Every exported symbol, by module. Signatures are authoritative as of v0.1.0;
each module's inline JSDoc carries the fuller contract. All `src/lib/`
modules attach to `self.VALYOU.<Name>` in the browser and export via
CommonJS under Node.

Conventions used below: `→` return type; `Promise<T>` means async; "scores"
always means an object keyed by every category id with values in [0, 1].

---

## VALYOU.Text (`src/lib/text.js`)

| Symbol | Signature | Notes |
| --- | --- | --- |
| `normalize` | `(input: string) → string` | NFKC, strip invisibles, lowercase, collapse whitespace. Non-strings → `""` |
| `deobfuscate` | `(input: string) → string` | Normalize + fold leetspeak/homoglyphs, remove intra-word separators, weld letter-spaced runs, collapse 3+ repeats. **Preserves word boundaries** |
| `tokenize` | `(input: string) → string[]` | Unicode-aware word split |
| `capsRatio` | `(input: string) → number` | Uppercase share of letters in the *raw* text, 0..1 |
| `punctuationBursts` | `(input: string) → number` | Count of `!!`/`??`-style runs |
| `clamp` | `(input: string, max: number) → string` | Word-boundary-aware truncation |
| `fingerprint` | `(input, salt) → Promise<string>` | base64url SHA-256 of salt + normalized text |
| `toBase64Url` / `fromBase64Url` | `(Uint8Array) → string` / `(string) → Uint8Array` | RFC 4648 §5, unpadded |

## VALYOU.ML (`src/lib/ml.js`)

The on-device ML assist. See [ML.md](ML.md) for the model, training, and bias
discussion.

| Symbol | Signature | Notes |
| --- | --- | --- |
| `DIM` | `65536` | Feature hash space |
| `FEATURE_VERSION` | `1` | Bumped when `features()` changes; `load` rejects a mismatched model |
| `MIN_PROB` | `0.6` | Probabilities below this contribute nothing (per-model ROC operating point) |
| `MAX_WEIGHT` | `0.5` | Ceiling on the model's scorer signal — below every default threshold |
| `fnv1a` | `(string) → number` | Deterministic 32-bit hash (training/serving must agree) |
| `features` | `(raw: string) → Uint32Array` | Sorted, unique feature bucket indices |
| `load` | `(modelData\|null) → boolean` | Load/unload; `false` on schema mismatch. `null` unloads |
| `ready` | `() → boolean` | Whether a usable model is loaded |
| `score` | `(raw: string) → number` | P(hateful) in (0,1); 0 with no model |
| `signalWeight` | `(p: number) → number` | Maps probability to a capped scorer signal weight |
| `decodeWeights` | `(modelData) → Float32Array` | Dequantize int8 weights (exported for tests) |

## VALYOU.ModelData (`src/model/model-data.js`)

The committed, trained weights — a plain data object (`{featureVersion, dim,
scale, bias, weights, meta}`) consumed by `ML.load`. Generated by
`scripts/train-model.js`; not hand-edited.

## VALYOU.Scorer (`src/lib/scorer.js`)

| Symbol | Signature | Notes |
| --- | --- | --- |
| `MIN_LENGTH` | `8` | Below this, text is unjudgeable (`tooShort`) |
| `ACTION_SEVERITY` | `{off:0, tag:1, blur:2, hide:3}` | Strictness ranking |
| `emptyScores` | `() → scores` | All-zero score object |
| `scoreText` | `(raw: string, rules?) → {scores, signals, max, top, tooShort}` | The classifier. `rules` = `{blockTerms, allowTerms}`; `signals` = `{id, why, weight}[]` (negative weight = mitigator) |
| `decide` | `(scores, settings, context?) → {action, category, score, reason}` | `context` = `{author?, signals?, hasVideo?}`. Strictest tripped action wins; in `hide` mode all video posts blur; with `media.flaggedVideoBlur` (default on) a flagged video blurs instead of collapsing |
| `describe` | `(categoryId, signals?) → string` | Human-readable reason line |
| `peak` | `(scores) → {top, max}` | Highest-scoring category |
| `blocksAutoplay` | `(videoMode, {approved, userActivated}) → boolean` | Pure autoplay-block decision; `true` = pause this play attempt |

## VALYOU.Store (`src/lib/store.js`)

| Symbol | Signature | Notes |
| --- | --- | --- |
| `configure` | `({local, session}) → void` | Test seam; defaults to `chrome.storage` |
| `get` | `(recordId, fallback?, where?) → Promise<value>` | Corrupt/absent → fallback; `LOCKED` propagates |
| `set` | `(recordId, value, where?) → Promise<void>` | Always encrypts |
| `remove` | `(recordId, where?) → Promise<void>` | |
| `update` | `(recordId, fallback, mutate, where?) → Promise<value>` | Read-modify-write (serialized by the single worker, not atomic) |
| `wipe` | `() → Promise<void>` | Clears both areas |
| `getRaw` / `setRaw` | as `get`/`set`, **no crypto** | **Wrapped-key blob only** — see CRYPTO-SPEC |

`where` is `"local"` (default) or `"session"`.
